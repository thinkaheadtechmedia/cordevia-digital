# Cordevia Digital — Media-Tech Agency Platform

A high-performance digital platform built for **Cordevia Digital** (formerly Tarana Group) — a modern media-tech agency driving YouTube channel growth, web engineering, SEO mastery, and digital solutions for creators and enterprises.

## Tech Stack

- **Framework**: React 18+ with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React (`lucide-react`)

## Key Features

- **Interactive ROI & Growth Estimator**: Real-time channel and digital revenue projections based on monthly views and niche CPM benchmarks.
- **Service Catalog & Pricing**: Interactive monthly/quarterly toggle with tier breakdowns across YouTube Management, Web Engineering, SEO, and Media Tech.
- **Client Case Studies & Testimonials**: Verified case studies with quantitative impact metrics.
- **Interactive Tools & Utilities**: Embedded tools including YouTube CPM calculators, title analyzer, tag generator, and SEO audit utilities.
- **E-Commerce & Checkout**: Course catalog, digital assets marketplace, shopping cart drawer, and interactive inquiry booking flows.
- **Global Search Modal & Mobile Navigation**: Fast responsive navigation, categorized search, and accessibility.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd cordevia-digital

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running locally at `http://localhost:3000`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build
npm run preview
```
